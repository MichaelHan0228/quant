# 双低可转债轮动策略 — 设计与实现计划

## 目标

在 `D:\quant\cb_double_low\` 新建项目（沿用仓库惯例：`fetch_data.py` + `backtest.py` + `README.md` + `data/` + `output/`），实现经典**双低可转债轮动策略**的完整回测与实盘信号工具，并用真实数据跑出回测结果写入 README。

**双低值 = 转债价格 + 转股溢价率 × 100**，按双低值升序持有前 N 只，定期轮动。

**溢价率计算**：`转股价值 = 正股收盘价 × 100 / 转股价(t)`，`溢价率 = 转债价 / 转股价值 - 1`。
转股价(t) 分段常数：初始值取 `INITIAL_TRANSFER_PRICE`；调整事件（下修/分红）实现时先探测东财调整记录端点（此前盲猜的 4 个 reportName 均不存在，需看东财 kzz 详情页实际 API）；**兜底：v1 用初始转股价 + 强赎/退市日期截断，缺失下修只会使双低值偏高（少买入，方向保守），在 README 已知问题中如实标注**。

## 策略规则（回测默认参数）

- **宇宙**（每个调仓日）：已上市 ≥10 个交易日、未公告强赎、距到期 >1 年、剩余规模 ≥3 亿、评级 ≥ A+、当日价格 ≤ 130 元
- **打分**：双低值 = 收盘价 + 溢价率×100，升序取前 **N=10**
- **轮动频率**：每日检查——每日收盘算信号，次日开盘执行（排名/缓冲逻辑与周频一致；每日检查使强赎公告等风险事件次日即可退出，不用等周末）
- **调仓缓冲**：挑战者双低排名比在持者低 ≥5 名才替换（抑制换手）
- **强制退出**：公告强赎→次日卖出；退市/到期→最后交易日收盘价了结
- **成本**：佣金万 1（转债无印花税、多数券商无最低 5 元）+ 单边滑点 0.1%，均参数化
- **基准**：中证转债指数 000832（mootdx 指数 K 线）+ 511380 可转债 ETF
- **回测区间**：2020-01 ~ 至今（转债市场 2020 后才有足够广度）

### 口径修复（2026-08-09）

两处数据口径问题修复，均消除前视/口径偏差：

**A. 剩余规模过滤误用发行规模快照**。旧逻辑用 `ACTUAL_ISSUE_SCALE`（发行规模）过滤 ≥3 亿，转债转股后剩余规模持续缩水（强赎前往往已不足 3 亿），口径错误。修复：采集官方交易所**累计转股比例时间轴**，`剩余规模(t) = 发行规模 × (1 - 累计转股比例asof(t)/100)`，按 `MIN_REMAIN_SCALE=3.0` 过滤（`MIN_ISSUE_SCALE` 废弃）。

- 沪市（11xxxx）：上交所 `query.sse.com.cn/commonQuery.do?sqlId=COMMON_SSE_SJ_ZQSJ_KZZZGTJ_L`（JSONP 分页，`pageHelp.data` 的 `TRADE_DATE_CVS`/`TOT_CONV_RATE`）
- 深市（12xxxx）：深交所 `szse.cn/api/report/ShowReport/data?CATALOGID=convertible_bond_conversion`（`PAGENO` 分页，`conversion_date`/`accumulated_conversion_ratio`，含千分位逗号需清洗；返回有同日重复行，按日期去重）
- 采集脚本 `fetch_conversion.py`（增量，`data/conversion/{code}.csv`）。实测验证：通22转债 110085 累计转股 0.14% → 剩余 119.83 亿，与东财 f84 剩余张数精确吻合
- 全量：1042 只中 715 只有转股记录、327 只无记录、0 失败

**B. 评级过滤用最新快照造成前视偏差**。旧逻辑用 universe 最新 `RATING` 全期过滤：① 22 只评级带 "sti" 后缀（东财附加标记，如 "AA+sti"）被精确匹配误杀；② 117 只当前评级 <A+ 的券历史上可能曾 ≥A+（如搜特转债上市时 AA，2022-02 才下调），全期剔除偷看了未来。修复：

- `clean_rating()` 归一化：去末尾大小写不敏感的 "sti" 后缀
- 对快照 <A+ 的 95 只券，用巨潮检索正股评级公告（`hisAnnouncement/query`，searchkey="评级"+"信用等级" 双关键词——临时下调公告标题只含"信用等级"不含"评级"，单搜"评级"会漏，搜特实测验证），标题过滤（含 跟踪评级/信用评级/信用等级，排除纯公司债报告），下载 PDF 用 pypdf 抽前 2 页正则解析等级变动（新增依赖 pypdf + cryptography）
- 采集脚本 `fetch_rating_events.py` → `data/rating_events.csv`：805 条事件 / 90 只券，parse_ok 304 条、parse_fail 501 条（失败多为跟踪评级报告封面评级表为图片/CID 字体乱码，pypdf 无法抽取；落盘供人工抽查）
- 回测资格表 `build_rating_eligibility()`：快照 ≥A+ → 任何日期合格；快照 <A+ → 首次跌破 A+ 的公告日 D 之前合格（t<D），之后剔除；无可用事件 → 始终不合格（保守）。搜特转债验证：cutoff=2022-02-18（A→BB 公告日）
- 已知残余偏差：部分"维持/下调"跟踪报告封面评级无法解析（parse_fail），个别券首次跌破日可能略晚于真实日期（如搜特 2021-06 跟踪评级已降至 A，但该报告解析失败，cutoff 取 2022-02）

**signal.py 同步**：评级过滤加 `clean_rating` 归一化；剩余规模改用东财 push2 `stock/get` 的 f84（剩余张数）——clist 不支持 f84（实测返回 '-'），故先按双低取前 50 候选再逐个补 f84，剩余规模=f84×100元 <3 亿剔除，输出加「剩余规模(亿)」列；push2 在本机 requests 直连 RemoteDisconnected（已知环境怪癖），重试 3 次失败后告警并跳过该过滤（不崩）。

**signal_qmt.py（QMT 版实盘信号，2026-08-09 新增）**：数据底座为本地 MiniQMT（xtquant），不经过东财 push2，规避其 IP 风控——转债实时价/成交额走 `get_full_tick`，剩余规模走 `get_instrument_detail` 的 `FloatVolume`（面值口径，与东财 f84×100 实测吻合），溢价率用回测同款转股价时间轴自算。过滤条件与回测全对齐。⚠️ xtquant 二进制 pyd 仅支持 Python 3.6~3.13，本机需 `py -3.13 signal_qmt.py` 运行；无 QMT 的机器继续用东财版 `signal.py`。口径验证：重银/兴业自算溢价率与东财推算值偏差 ≤0.1pp。
另注：QMT 历史债券日线价格字段全为 0（本终端无债券历史行情权限），不能用于回补日线缓存；沪深转债板块列表滞后于最新上市（次新券拿不到快照，但不影响——上市不满 10 日本来就会被过滤）。

### 执行时点实验（2026-08-09，`--exec` 参数）

验证"当日成交（T+0 节奏）"可行性，三组对比（N=10，其余口径同终版）：

| 执行模式 | 总收益 | 年化 | 最大回撤 | 夏普 | 结论 |
|---|---|---|---|---|---|
| next_open（次日开盘，默认） | 197.4% | 17.97% | -15.2% | 1.37 | 基准 |
| same_close（当日收盘） | 197.4% | 17.97% | -14.8% | 1.38 | ✅ 等价，支持"14:50 出信号+尾盘下单"的 T+0 节奏 |
| same_vwap（当日均价 (H+L+C)/3 代理） | 102.5% | 11.29% | -17.4% | 0.92 | ❌ 差 6.7pp 年化，禁止摊单到全天 |

结论：双低是均值回归型信号，入选券收盘常贴日内低点（买点）、止盈券收盘常贴日内高点（卖点），成交价应贴收盘价；当日收盘成交与次日开盘等价、回撤略优。注意 same_close 有轻微前视（收盘价定排名又以收盘价成交），实盘对应"14:50 快照 + 尾盘竞价"，偏差可接受。日内触发式止盈（盘中破 140 立即卖）需分钟线回测，未覆盖。

### 止盈/天花板/规模过滤网格与隔离实验（2026-08-07 下午，v2 评级口径）

**评级解析修复**：`reparse_rating_events.py`（PDF 缓存 `data/rating_pdf_cache/`，抽页 2→40、分级规则链 R0-R5、鹏元封面表粘连拆分）将 parse_ok 从 304/805（37.8%）提升到 **674/805（83.7%，可解析集合 96.3%）**；剩余 131 条中 103 条扫描件无文本层不可解析。v2 已切换为回测数据源（v1 备份 `rating_events_v1_backup.csv`）。

**止盈 3×3 网格**（hold-max × tp-prem，v1 评级 + 部分转股数据）：
130 档 13.33%（三档 tp 相同，验证分支正确）/ 140 档 12.4~12.7% / 150 档 12.0~12.3%。当时结论是"止盈关闭最优"——**后被证明是受污染结论**（见下）。

**双低值天花板**：150 档夏普微升但在组合实验中伤收益（13.33%→12.23%），默认关闭（`MAX_DOUBLE_LOW=0`）。

**⚠️ 转股数据不对称污染事件（重要教训）**：`szse.cn` 对本机 IP 连接级封锁（TCP 重置，多轮重试无效），深市 564 只券转股比例缺失 → 缺失券按"未转股"兜底 → 剩余规模过滤**对沪市生效、对深市失效**，同一规则两种待遇。此状态下所有含该过滤的实验结论均不可信。修正方法：2×2 隔离实验（v2 评级）：

| | 剩余规模过滤开 | 剩余规模过滤关 |
|---|---|---|
| 止盈开 | 12.73% / -20.5% / 夏普0.99 | **14.35% / -18.9% / 夏普1.09 / Calmar0.76** |
| 止盈关 | 12.92% / -21.9% / 1.01 | 13.80% / -21.7% / 1.06 |

结论反转：**止盈线打开是更优的**（此前"关闭更优"系过滤不对称所致）；剩余规模过滤在数据补齐前**暂关**（`MIN_REMAIN_SCALE=0`），回退发行规模 ≥3 亿兜底（保证两市对称）。
