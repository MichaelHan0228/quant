## 目标

在 `D:\quant\cb_double_low\` 新建项目（沿用仓库惯例：`fetch_data.py` + `backtest.py` + `README.md` + `data/` + `output/`），实现经典**双低可转债轮动策略**的完整回测与实盘信号工具，并用真实数据跑出回测结果写入 README。

**双低值 = 转债价格 + 转股溢价率 × 100**，按双低值升序持有前 N 只，定期轮动。

**溢价率计算**：`转股价值 = 正股收盘价 × 100 / 转股价(t)`，`溢价率 = 转债价 / 转股价值 - 1`。
转股价(t) 分段常数：初始值取 `INITIAL_TRANSFER_PRICE`；调整事件（下修/分红）实现时先探测东财调整记录端点（此前盲猜的 4 个 reportName 均不存在，需看东财 kzz 详情页实际 API）；**兜底：v1 用初始转股价 + 强赎/退市日期截断，缺失下修只会使双低值偏高（少买入，方向保守），在 README 已知问题中如实标注**。

## 策略规则（回测默认参数）

- **宇宙**（每个调仓日）：已上市 ≥10 个交易日、未公告强赎、距到期 >1 年、剩余规模 ≥3 亿、评级 ≥ A+、当日价格 ≤ 130 元
- **打分**：双低值 = 收盘价 + 溢价率×100，升序取前 **N=15**（变体 10/20 对比）
- **轮动频率**：周频——周五收盘算信号，下周一开盘执行（与仓库其他项目同口径）
- **调仓缓冲**：挑战者双低排名比在持者低 ≥5 名才替换（抑制换手）
- **强制退出**：公告强赎→次日卖出；退市/到期→最后交易日收盘价了结
- **成本**：佣金万 1（转债无印花税、多数券商无最低 5 元）+ 单边滑点 0.1%，均参数化
- **基准**：中证转债指数 000832（mootdx 指数 K 线）+ 511380 可转债 ETF
- **回测区间**：2020-01 ~ 至今（转债市场 2020 后才有足够广度）

## 实施步骤

1. **建项目骨架** `D:\quant\cb_double_low\`（config.py / fetch_data.py / backtest.py / signal.py / README.md / data/ / output/）
2. **fetch_data.py**（全部增量缓存到 data/，重复运行只补增量）：
   - `universe.csv` ← 东财 RPT_BOND_CB_LIST 全量 1047 只
   - `redeem.csv` ← akshare bond_cb_redeem_jsl()
   - `data/cb_daily/{code}.csv` ← 新浪 per-bond 日线（~0.4s 限速，失败切东财重试）
   - `data/stock_daily/{code}.csv` ← mootdx 正股日线（offset 800/批循环）
   - `transfer_price.csv` ← 探测东财调整记录端点；拿不到则用初始转股价兜底并在 README 标注
3. **backtest.py**：周频轮动引擎 + 绩效指标（总收益/年化/MDD/夏普/Calmar/周胜率/交易次数/年度收益），输出 `output/equity_curve.csv`、`trades.csv`；跑 N=10/15/20 三变体 + 基准对比
4. **signal.py**：实盘工具——拉东财实时比价表，输出当前双低 Top-N 清单与在持差异（每周 5 分钟操作指引）
5. **README.md**：按仓库 strategy.md 风格写策略文档：规则、参数表、防穿越说明、真实回测结果、年度收益表、已知问题（转股价调整兜底的影响、住宅 IP 风控等）、实操部署
6. **验证**：实跑 fetch（可抽样先跑通 50 只再全量）+ 回测，确认结果合理（双低策略 2020-2024 历史年化大致 10-20% 区间、2025 后转债高估值期收益回落，若结果离谱须排查数据/逻辑错误）
7. 不做 git 提交（留给用户决定）
