# 四象限风格轮动策略（v1 最简版回测）

大盘成长 / 大盘价值 / 小盘成长 / 小盘价值 四象限轮动：按风险调整动量选择风格象限，
带 MA60 风控过滤，资金随市场风格高低切。

## 标的

国证风格指数（mootdx `index_bars` 拉取，数据缓存于运行目录 `data_cache/`）：

| 代码 | 指数 |
|---|---|
| 399372 | 大盘成长 |
| 399373 | 大盘价值 |
| 399376 | 小盘成长 |
| 399377 | 小盘价值 |

执行层对应 ETF：300成长 / 300价值 / 1000成长 / 1000价值 ETF。

## 策略规则（v1）

1. **信号**（每个调仓日收盘后计算）：风险调整动量得分 = 加权收益率 / 波动率
   - 加权收益率 = 0.4×过去20日 + 0.4×过去60日 + 0.2×过去120日收益率
   - 波动率 = 过去120日日收益率标准差
2. **调仓**：每周最后一个交易日收盘调仓。选得分第1名；
   滞回机制——当前持仓仍在前2名则不换仓。
3. **风控**：被选指数收盘价 < MA60 → 持现金（年化2%）；全部破位同样持现金。
4. **成本**：换仓扣双边 0.002；现金进出不扣费。
5. 回测区间 2019-01-02 → 2026-07-31，初始净值 1.0。

参数集中在 `backtest.py` 顶部常量，改参后重跑即可（数据已缓存）。

## 回测结果（v1，2019-01-02 → 2026-07-31，约7.6年）

| 指标 | 轮动策略 | 等权基准（周再平衡） |
|---|---|---|
| 年化收益 | 5.26% | 7.68% |
| 累计收益 | 45.36% | ~71.6% |
| 最大回撤 | -43.91% | -38.69% |
| 夏普（rf=2%） | 0.17 | 0.30 |
| 卡玛 | 0.12 | — |
| 超额年化 | **-2.42%** | — |

- 换仓 12 次（年均 1.6 次，滞回机制有效压制换手）；持现金占比 28.73%；周胜率 65.12%
- 四指数买入持有年化 / 最大回撤：
  大盘成长 9.45% / -59.97%；小盘成长 7.87% / -52.52%；
  小盘价值 6.84% / -36.09%；大盘价值 4.11% / -34.19%

净值曲线见 `nav.png`，逐日净值见 `nav.csv`，汇总见 `summary.txt`。

## 结果分析

- **2019–2020 大幅跑赢**（2020 年 +39.85% vs 基准 +23.53%）：动量成功咬住大盘成长主线，
  MA60 在 2020-03、2022 年初多次切现金躲跌，周胜率 65% 也源于此。
  趋势连贯的年份这套逻辑成立。
- **2021 年后持续跑输**：风格进入高频切换期（2021 大小盘切换、2024 年初微盘崩盘、
  2024-09 暴力反转、2025 成长行情），20/60/120 日动量窗口太慢，周频信号屡屡踏空或追高：
  - 2022 年（-26.59% vs 基准 -20.87%）：阴跌-反弹交替中 MA60 反复打脸；
  - 2025 年（+10.39% vs +23.28%）：动量滞回没跟上成长行情启动。
- 最大回撤 -43.91% 发生在 2021 高点 → 2024 年初：MA60 能躲单边快熊，
  但对三年震荡阴跌无能为力。
- **结论：动量轮动在趋势市有效，在风格快速轮动市失效；v1 骨架整体不如等权躺平。**

## 改进方向（v2 候选）

1. **信号提速**：动量窗口 20/60/120 → 10/20/60；或改用风格价格比的趋势信号
   （小盘/大盘、成长/价值比值的均线交叉），对切换更敏感。
2. **换仓确认**：仅当第1名得分显著领先第2名（超阈值）时才换仓，减少噪音切换。
3. **风控逻辑改良**：跌破 MA60 减半仓而非清仓；或改 MA20/MA60 金叉死叉。
4. **拥挤度/反转项**：叠加成交占比、换手率等拥挤度指标，极端分位提前离场
   （2024 年初微盘崩盘前小盘成交占比已到极端分位，纯动量会在山顶接盘）。
5. **现金端收益假设**：28.7% 时间持币，现金改按国债 ETF 收益，年化约 +0.5%。
6. **参数敏感性扫描**：对动量窗口/MA周期/调仓频率做网格扫描，
   区分「参数问题」还是「骨架问题」。

```bash
python backtest.py
```
