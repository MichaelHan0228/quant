# ETF 多因子动量轮动策略

基于乖离/斜率/效率三因子动量评分的 ETF 轮动策略，本地回测 + 每日信号。
策略原型来自猫哥AI量化公众号文章（聚宽年化 42% / QMT 年化 43%），
本项目在本地复现并做了系统的降回撤改进。

## 最终配置（run.py 默认值）

- **标的池**：512890 红利低波、159949 创业板50、513100 纳指、518880 黄金、159985 豆粕、511260 十年国债
- **持仓**：评分 Top2 等权（各 50%）
- **止损**：持仓期最高收盘回落 13% 清仓（只卖破位标的，不连坐），冷却 5 天；
  **浮盈收紧**：峰值浮盈 ≥20% 后止损线收紧为 8%
- **仓位控制**：组合近 20 日年化波动率 > 20% 时按 0.25 步进降档（exposure = 20%/实现波动），
  超出部分留现金；波动回落自动加回
- **调仓阈值**：挑战者分数须超过在持者 + 0.5×|在持者分数| 才换仓
- **窗口**：25 天；**权重**：乖离 0.3 / 斜率 0.3 / 效率 0.4

回测（2020-01 ~ 2026-09，默认配置）：年化 37.5%，夏普 1.88，
最大回撤 -12.7%，卡玛 2.94。

进攻型备选（原版 4 池 k=1 + 3×ATR 止损）：年化 ~49%，回撤 -23.1%，卡玛 2.12。

## 使用

```bash
python run.py backtest                 # 默认配置回测，输出 output/ 报告
python run.py backtest --start 2014-01-01   # 长周期回测（动态池：未上市标的不参与）
python run.py signal 512890            # 今日信号（传入当前持仓代码）
python run.py sweep                    # 参数遍历（原版4池固定网格）
python run.py backtest --top-k 1 --stop 0 --atr 3.0 \
    --codes 512890,159949,513100,518880   # 进攻型配置
```

## 长期回测（2014 起，动态标的池）

支持从 2014 年甚至更早回测：标的未上市的年份自动不参与轮动
（并集日历 + 各标的自身 warmup 25 根后才进入候选）。
上市时间线：纳指 2013-05 / 黄金 2013-07 / 创业板50 2016-07 / 十年国债 2017-08 / 红利低波 2018-12 / 豆粕 2019-12。

2014-01 ~ 2026-09（默认配置）：年化 21.4%，夏普 1.37，最大回撤 -22.3%，卡玛 0.96。
**逐年收益高度不均**：2015 -1.3%、2017 -0.5%、2018 -8.1%（池内标的少，动量 whipsaw），
2019 年池子补齐后才进入高收益区。结论：策略的漂亮业绩
有一部分是"标的选择的事后偏见"，早期 2-3 只标的时表现平庸，预期管理要做好。

十年国债的价值在长样本危机期显形：2018 熊市从 -13.7%（无国债）收窄到 -8.1%，
整体回撤 -25.7%→-22.0%；2020 起窗口则为平手（负相关资产的价值取决于样本里有没有危机）。

依赖：`pip install mootdx requests pandas scikit-learn matplotlib`

## 改进实验结论（2026-08 验证）

| 改动 | 结论 |
|---|---|
| score>0 过滤 | 无效（z-score 恒有正值） |
| 均线过滤（MA25/严格） | 性价比差，躲不过闪崩还增调仓 |
| Top2 等权 | 回撤 -27.5%→-17.3%，夏普反升，有效 |
| 固定止损 10% | 免费午餐，k=1/k=2 均小幅改善 |
| ATR 止损 | k=1 最优 3×ATR（卡玛 2.12）；2×太紧被洗；k=2 不如固定10% |
| 分标的 ATR 倍数 | 无效（以 ATR 计的噪音四标的同构） |
| +国债ETF(511010) | 拖累收益，避险角色与黄金/红利重叠 |
| +豆粕ETF | **Top2 模式唯一帕累托改进**，相关性 ≤0.09 |
| +恒生科技/有色/创新药 | 与创业板相关性 0.55+ 同质；8池年化 -8.5pp、回撤 -16.4%→-25.1%，排除 |
| +日经ETF | k=1 模式边际改善，与纳指相关 0.67，可选 |
| +十年国债ETF(511260) | 2020起平手（夏普 1.72）；2014起回撤 -25.7%→-22.0%、卡玛 0.84→0.99、2018年 -13.7%→-8.1%，危机保护型，可选 |
| 相关性扫描（scan_corr.py） | 16只候选中低相关仅 原油LOF(0.22)/长债(0.23~0.27)；标普500(0.90)/日经(0.72)/德国(0.67)/白银(0.62)/煤炭(0.62)/电力(0.58)/可转债(0.65) 均与池内同质 |
| +量能因子（量比5/25，第4权重） | 权重0.2：2020起回撤 -16.4%→-14.0% 但年化 -2.1pp；2014起全面略差；权重0.3 明显变差。ETF量能含做市/申赎噪音，不构成帕累托改进，不入默认（`--weights` 传4个值可启用） |
| +原油LOF(501018) | 相关性仅0.22但波动形态太暴（跳空多），13%止损频繁误触发，回撤 -16.4%→-22.2%，排除 |
| Top3 等权 | 年化 -11.8pp（36.0%→24.2%），过度稀释，Top2 仍最优 |
| 低波惩罚（总分-0.3×z(波动率)） | 又是收益换回撤（回撤 -13.6% 但年化 -9pp、卡玛 2.0<2.19）。池子利润来自高波资产趋势段，压波动=压利润 |
| 浮盈收紧止损（20%→8%） | **有效，已入默认**：2020起四项全胜（年化36.0%→36.7%、卡玛 2.19→2.41、回撤 -16.4%→-15.2%），2014起持平无害，换参数(25%→10%)结果接近 |
| 平台止损（swing箱体/prevhigh前高/volprofile筹码） | **三方案全败**（卡玛 1.29/1.34/1.92 vs 纯浮盈收紧 2.41）：亏损头寸"破平台即走"≈紧止损被洗（调仓 300~697 次），是规则本身的问题而非箱体识别算法问题，弃用 |
| 行业ETF池（20只一级行业） | **策略失效**：年化 1.6%、回撤 -57.4%。全行业同为A股beta、无防御资产，高相关池内 z-score 排名≈噪音，2022/2024 无处可躲 |
| +宽基（上证50/中证1000） | 无新收益源（与创业板50相关 0.67/0.80），年化 -5.3pp；中证红利/创业板指与池内标的 0.90/0.99 纯重复 |
| 组合波动率目标（20%/20日，0.25步进） | **有效，已入默认**：2020起四项全胜（回撤 -15.2%→-12.7%、卡玛 2.41→2.94、年化 36.7%→37.5%），2014起夏普 1.32→1.37 其余持平，18%/40日换参稳健；目标15%太紧被否（频繁介入、长样本拖累）。机理：只在组合波动异常放大时机械降仓，不判断方向 |
| QDII 溢价过滤（>3%禁新买，需 fetch_premium.py） | 回测中性（36.3% vs 36.7%），价值在实盘执行保护——2025 起纳指ETF 六成天数溢价 >3%，实盘建议常驻开启（`--premium-limit 0.03`） |
| 滑点敏感性 | 单边成本 万1→千2：年化 36.7%→28.0%、卡玛 2.41→1.71，衰减平滑无断崖，策略不依赖精确成交 |

## 交易流程（每日）

1. 收盘后数据自动增量更新（腾讯前复权K线）
2. 每只 ETF 最近 25 天算三因子 → 横截面 Z-Score → 加权总分
3. 止损检查：回落 ≥13% 次日卖出破位标的（不连坐；峰值浮盈 ≥20% 的标的收紧为 8%）
4. 波动率目标：组合近 20 日年化波动 >20% 时仓位降档（0.25 步进），超出部分留现金
5. 目标 = 总分前 2 名，阈值机制防频繁换仓
6. 次日开盘执行，等权 50/50

## 风险提示

- 全部回测为样本内结果，参数经过遍历选优，存在过拟合风险
- 豆粕ETF 规模小、有期货展期损耗，大资金注意流动性
- 回测假设开盘价成交、无滑点，实盘会有损耗
- 本策略连续换仓踩错时单月回撤可达 -10% 以上，需有纪律执行
- 仅供研究，不构成投资建议
